## Tool issues
- launcher: fits contact_normal only tests the first object's triangles, so any edge of the stop face lying inside the other part's face puts the neighbouring face in the contact and fails it (worked round with a 0.3 relief on the hood end face). slide_out `flex` names the stationary part, so a snap arm that rides ON the mover can only be bounded through its allow's max_mm3.
- none blocking. cadlib has no snap / bayonet / dovetail helper (snaps are built from G primitives); `flexures` warns (not fails) on vertical hooks under 15 MPa, so they go to accepted_warns with the stress.
- accepted_warns: all 22 carried entries use the deprecated substring "match" form (config warn); the finish item rewrites them as {check, kind, object, why}.
- feeder: distances `ray` rows cast +dir to b and -dir to a from the origin, so the origin must sit in the gap (an origin inside a reads the wrong face; checks-config does not say so).
